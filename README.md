# Heart-Attack-Risk-App
An ML app analyzes user data and predicts based on factors using the best of two models (Random Forest or Linear Regression). This project uses online data, preprocesses it, trains the model, and measures its performance. It’s deployed on a Streamlit web application for real-time experience.


Features<br>

Exploratory Data Analysis (EDA)<br>
Feature scaling using StandardScaler
Multiple ML models implemented:
Logistic Regression
Support Vector Machine (SVM)
Random Forest Classifier
Model evaluation using:
Accuracy
Precision
Recall
F1-Score
Confusion Matrix
Best model saved using joblib
Interactive Streamlit web app for user input & prediction
